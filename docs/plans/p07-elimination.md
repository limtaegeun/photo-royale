# P07 M3 탈락 모델 — 아웃·생존을 원장에서 파생한다

- **작성일**: 2026-09-16 (M1·M2 배포 뒤. P07 §7 로드맵의 M3, `docs/plans/p07-round-scoring.md` 선행)
- **범위**: 일반전 기준의 탈락(아웃)·생존 판정, 생존 보너스 +5, 콕핏 "N팀 생존" 실데이터, 판정 시트의 탈락 팀 표시. 꼬리잡기 편입·왕 아웃 감점·스태프전 수동 아웃은 이 모델 위에 M4가 얹는다.

## 0. 한 줄 요약

**탈락은 새 필드가 아니라 원장 `hits`에서 파생한다** — 팀이 맞은 횟수가 라이프에 닿으면 아웃이다. 판정 배치가 이미 피격 완장별 `hits`를 올리고 있으므로(M1) 쓰기 경로·rules 변경이 없고, 재시작→재종료가 result를 덮어쓰는 기존 정합도 그대로다.

## 1. 결정 (기획자 확인 없이 정한 것 — 표시된 것은 확인 요청)

| # | 항목 | 결정 | 근거 |
|---|---|---|---|
| 1 | 라이프 | **팀 1, 1인 팀 2** | 앱 규칙 카드(1인 팀: "목숨과 포인트가 2배입니다") — 규칙서의 1인 팀 보정 |
| 2 | 아웃 판정 | `hits[완장] >= 라이프` (파생값) | 승인 = 원킬 1건. 별도 저장 없음 → 정정 시 어긋날 사본 없음 |
| 3 | 아웃 팀의 제출 | **콕핏에서 셔터·제출 잠금 + "탈락" 안내** (rules는 안 막음) | 서버 차단은 rounds 문서 get 1회가 더 들고 호스트 재량 모델과 맞지 않음. 클라 잠금 + 판정 시트 표시로 막는다. 서버 차단은 후속 후보 |
| 4 | 아웃 팀을 또 잡으면 | 판정 시트에서 아웃 팀은 **선택 비활성 + "탈락" 배지** | 호스트 실수 방지. 강행하고 싶으면 반려 후 안내(재판정 없음) |
| 5 | 생존 보너스 | **+5 — 라운드 종료 시 아웃이 아닌 팀원 각자** (결정 5 확정분) | 킬 없이 살아남은 사람이 킬 없이 잡힌 사람보다 한 등급 위 |
| 6 | 콕핏 표시 | `생존 N / M팀` (원장 없으면 기존 `M팀 참가`) | 배정 팀 수 자리에 실데이터 |
| 7 | 1인 팀 "포인트 2배" | **미적용 — 기획자 확인 요청** | 규칙 카드 문구지만 P07 결정(팀 점수 동일 지급, 1인 팀 중립)과 충돌. 확인 전까지 라이프만 2 |
| 8 | 원장 없는 라운드 | 탈락 없음(전원 생존 취급 안 함 — 보너스도 없음) | 원장이 없으면 정산 자체가 없다(M1) |

## 2. 데이터 · 계산

- 새 필드 없음. `ModeScoringInput`(teams·hits)만으로 `livesOf(teams, 완장)` = 팀원 1명이면 2, 아니면 1 · `isTeamOut(input, 완장)` = `hits[완장] >= livesOf`.
- 일반전 정산 = 킬 원점수(10·3배 30) + **생존 +5**(아웃 아닌 팀). `modes/normal.ts`의 `scoring`이 소유.
- round-ledger가 원장 문서용 래퍼(`teamOutStatus(ledger)`, `aliveTeamCount(ledger)`)를 노출 — 콕핏·판정 시트·운영 화면이 같은 함수를 쓴다.
- 재시작 후 추가 판정으로 hits가 더 오를 수 있다 — 아웃은 되돌리지 않는다(마지막 종료가 정본, M1 §9-1과 같음).

## 3. 화면

| 화면 | 변경 |
|---|---|
| 콕핏 | 현재 차수 원장 구독. 내 팀 아웃 → 셔터 비활성·제출 차단·"탈락" 상태 카드(일시정지 카드 패턴). 우측 칩 `생존 N / M팀` |
| 판정 시트 | 아웃 팀 옵션 비활성 + `탈락` 배지 |
| 운영 미리보기 | 자동 반영(생존 +5가 원점수에 들어감) |

## 4. 검증

- 계산기: 라이프(2인 1·1인 2), 아웃 경계(hits = 라이프), 생존 +5(아웃 제외), 3배 킬과 합산.
- 콕핏: 아웃 전/후 셔터·제출·문구, 원장 없을 때 기존 표기.
- 판정 시트: 아웃 팀 비활성·배지, 아웃 아닌 팀 정상.
- live-qa: 승인으로 팀 아웃 → 콕핏 잠금(타 클라이언트 기준) → 종료 시 생존 팀 +5 → 순위 반영.
