## 0. 한 줄 요약

게스트 대기실의 준비 버튼을 화면 하단에 띄우고(준비 인원 진행률 포함), 룸 카드 자리를 "내 체크인" 단계 카드로 바꾸고, 명단에서 내 칩에 `나` 표시를 붙인다. 40명 방에서도 첫 화면에서 지금 무엇을 눌러야 하는지 보인다.

## 1. 문제

1. 버튼이 화면 흐름 맨 끝에 있다. 40명 방이면 명단이 길어서 첫 화면에 버튼이 없다.
2. 안전 수칙 카드도 흐름 끝에 있어서 `확인하고 준비 완료`가 무엇을 확인하는지 첫 화면에서 보이지 않는다.
3. 명단에서 내 칩을 찾기 어렵고, 내가 아직 대기 묶음에 있다는 것을 알아채기 어렵다.
4. 누른 뒤에는 회색 비활성 버튼 `준비 완료`가 남아 "아직 못 누른다"로도 읽힌다.

## 5. 검증

- 정적: type-check, lint, vitest 1271건
- 실검증: 저장소 `firestore.rules`를 켠 Firebase 에뮬레이터에 40명 방(28명 준비)을 만들고, 수정 전(origin/main)과 수정 후 프로덕션 번들을 같은 방에 붙여 항목 28건을 돌렸다. 28건 모두 기대대로 나왔다. 준비는 390×844 터치로 눌렀고 서버 문서와 진행자 화면으로 반영을 확인했다
- 첫 화면: 수정 전은 버튼이 1242px(화면 844 밖)에 있었고, 수정 후는 772~828px 로 첫 화면 안에 있다
- 연타 3번에 준비 쓰기는 1번, 쓰기 채널을 막으면 8.2초 뒤 바 안에 불안정 안내가 뜨고 풀린 뒤 2.0초에 서버에 반영됐다
- 누르는 자리: 게스트·진행자·배정 카드 화면 49곳을 터치·마우스로 눌렀고 수정 전과 다른 곳은 없다
- 찾아서 고친 결함: 라운드가 끝나 대기실로 돌아온 게스트에게도 "진행자가 전원 준비를 기다리고 있어요"가 보여서, 게임 중에는 완료 상태 줄만 남겼다
- 실기기 iOS 홈 인디케이터 여백은 보지 못했다. 값 계산(바 50px · 섹션 0px)은 safe-area 값을 34px 로 바꿔 확인했다
