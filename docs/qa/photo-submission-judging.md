# 사진 제출 및 호스트 판정 QA Test Case

- **브랜치**: `feat/p05-photo-submission-judging`
- **작성일**: 2026-07-26
- **크리티컬리티**: 오프라인 실시간 게임의 사진 제출·불가역 판정 경로 — **장애 허용 불가**
- **기획 근거**: `docs/plans/p05-photo-submission-judging.md`
- **검증 환경**: local Vite + 실제 Firebase(`photo-royale-scc`, STANDARD/FIRESTORE_NATIVE). 신규 기능이라 main baseline은 기능 대조가 불가능해 local 단독 검증한다.
- **최종 상태**: **코드 Blocker 해소, 실기기 P0 보류** — J-11 수정 통과, Q-07 stale 큐 차단 확인
