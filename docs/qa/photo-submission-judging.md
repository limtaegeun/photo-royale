- **브랜치**: `feat/p05-photo-submission-judging`

### 실측·증거

- 320/390/430 큐: 행 x=24px, 폭=272/342/382px, 높이=98.59px, 가로 overflow 0px.
- 390 시트: 폭 390px, 높이 717.4px. 제출 팀 A disabled=true, 확정은 선택 전 disabled=true → 팀 C 선택 후 false.
- 실제 큐: `대기 1건`, `팀 A · 파랑`, `게스트1667`, `방금 제출`; 반려 후 `대기 0건` 및 `킬샷을 반려했어요.`.
- 외부인 공격 계정 결과: `{ kind: 'success', count: 1, photos: ['data:image/jpeg;base64,/9j/2Q=='] }`.
- 시각 증거 파일: `.qa-shots/photo-submission-judging/queue-{320,390,430}.png`, `sheet-390.png`, `empty-390.png`, `real-{queue,rejected}-390.png`.
- 실제 이미지와 data URI를 포함한 HTML 보고서는 만들지 않았다. P0 실패로 QA 완료 보고서 단계에 진입하지 않았으며, 원본 증거는 삭제하지 않았다.

### 판정

- 정적 게이트는 전부 통과했지만 **보안 규칙 점수 1/5(Critical)** 이며 P0 실패다.
- `firestore.rules:225`에 host/participant 멤버십 검증을 추가하고, pending 큐를 제출 차수로 격리한 뒤 전체 qa-flow를 다시 수행해야 한다.
- 실기기 iOS/Android, 장시간/잠금 복귀, 승인 정상 경로(다른 팀 1개 이상)는 미검증이다.
